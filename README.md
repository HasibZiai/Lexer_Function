# CPSC323_Project1
Project 1 for CPSC 323

The project is being run as a script using Ubuntu

You can comment out the directive (#!/usr/bin/python) if you're using some other environment

If you want to use linux to run it, just change modifications after downloading like so:
chmod a+x proj1.py
  
Then run the script by typing
./proj1.py
